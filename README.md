## 🧠 Homework Overview

### **HW1 – Python Fundamentals & Student Grade Management**
A console-based **Student Grade Management System** implemented using core Python concepts:
- dictionaries, lists, loops, and functions
- file I/O (CSV and text files)
- input validation and error handling
- GPA calculation and reporting

Focus: procedural programming and real-world data handling. :contentReference[oaicite:0]{index=0}

---

### **HW2 – Data Analysis with NumPy, Pandas, and Matplotlib**
A synthetic **university course performance analysis** project involving:
- data generation with NumPy
- data cleaning and aggregation using Pandas
- statistical analysis and derived metrics
- extensive visualization (bar charts, histograms, boxplots, scatter plots, heatmaps, etc.)

Focus: exploratory data analysis and visualization workflows. :contentReference[oaicite:1]{index=1}

---

### **HW3 – K-Nearest Neighbors (KNN) from Scratch**
Custom implementations of KNN classifiers for:
- numeric-only features (Euclidean distance)
- categorical-only features (Hamming distance)
- mixed numeric & categorical features (weighted distance)

Includes comparison with `sklearn`’s `KNeighborsClassifier` and analysis of the effects of **K** and distance weighting.

Focus: distance metrics, algorithm behavior, and model sensitivity. :contentReference[oaicite:2]{index=2}

---

### **HW4 – Gradient Descent Optimization**
Implementation of **Gradient Descent** to minimize a two-variable convex function:
- analytical gradient computation
- experiments with different learning rates
- impact of initialization points
- 3D surface plots and 2D contour plots showing optimization paths

Focus: optimization dynamics and convergence behavior. :contentReference[oaicite:3]{index=3}
